# E-Commerce Sales, Customer & Business Performance Analytics

## Project Overview

This project focuses on analyzing e-commerce business performance using Python, Excel, Power BI, and Machine Learning.

The objective is to transform raw e-commerce data into meaningful business insights by analyzing sales performance, profitability, customer behavior, product performance, marketing activities, delivery operations, returns, and customer churn.

The project also includes machine learning prediction analysis to identify potential delivery delays, product returns, and customer churn risks.

## Project Objectives

- Analyze overall sales and profit performance.
- Understand customer purchasing behavior and repeat purchases.
- Measure customer retention and customer lifetime value.
- Identify top-performing products and categories.
- Evaluate marketing campaigns and discount performance.
- Monitor delivery performance and delays.
- Analyze product returns and customer experience.
- Predict customer churn, delivery delays, and product returns using machine learning.

## Dataset Information

The project uses e-commerce datasets covering the period from 2021 to 2025.

| Dataset | Records |
|---|---:|
| Sales Data | 138,116 |
| Customer Data | 25,000 |
| Order Items Data | 397,569 |
| Product Data | 1,175 |

## Tools & Technologies

- **Python:** Data cleaning, data preprocessing, exploratory data analysis, and machine learning.
- **Pandas & NumPy:** Data manipulation and analysis.
- **Matplotlib & Seaborn:** Data visualization.
- **Microsoft Excel:** Data inspection and preparation.
- **Power BI:** Interactive dashboards and business reporting.
- **DAX:** KPI calculations and business metrics.
- **Machine Learning:** Customer churn, delivery delay, and return predictions.

## Project Workflow

1. Data Collection – Collected and organized the e-commerce datasets.
2. Data Cleaning – Handled missing values, duplicates, and data inconsistencies using Python.
3. Exploratory Data Analysis – Analyzed sales, customers, products, and operational performance.
4. Data Transformation – Prepared datasets for reporting and analysis.
5. Data Modeling – Designed relationships between fact tables and dimension tables in Power BI.
6. Dashboard Development – Created interactive reports using Power BI and DAX.
7. Machine Learning – Developed prediction models for customer churn, delivery delays, and product returns.
8. Business Analysis – Used dashboard insights and prediction results to understand business risks and opportunities.

## Machine Learning Prediction Analysis

The project includes three prediction areas:

### 1. Customer Churn Prediction
Analyzes customer churn probability and identifies customers with potential churn risk.

### 2. Delivery Delay Prediction
Analyzes delivery delay probability and identifies orders with potential delivery risks.

### 3. Product Return Prediction
Analyzes return probability and identifies orders with potential return risks.

Prediction results are visualized in Power BI using probability distributions, actual-versus-predicted comparisons, risk analysis, and model performance metrics.
